# README 预览器

一个简洁优雅的 Markdown 文件预览工具，可嵌入到任何网页中作为**使用说明文档**展示。

## 功能特点

- **实时渲染**：自动加载并渲染同目录下的 `README.md` 文件
- **状态指示**：顶部状态栏实时显示加载状态（加载中 / 完成 / 错误）
- **一键刷新**：点击刷新按钮即可重新加载文件内容
- **内容变化检测**：自动检测文件内容是否更新
- **响应式设计**：适配桌面端和移动端浏览

## 使用方法

将本工具作为项目的使用说明页面：

1. 将 `README.html` 放到您项目的 `index.html` **同一目录**下
2. 在同一目录下编写 `README.md` 作为使用说明文档
3. 在您的网站导航或页面中，添加链接指向 `README.html`
4. 用户打开 `README.html` 后即可看到格式化的使用说明

>  **提示**：`README.html` 会自动加载同目录下的 `README.md` 文件并渲染为网页，您只需维护 Markdown 文档即可。

## 技术栈

| 技术 | 说明 |
|------|------|
| HTML5 | 页面结构 |
| CSS3 | 样式与布局 |
| JavaScript (ES6+) | 交互逻辑 |
| [Marked.js](https://cdn.jsdelivr.net/npm/marked/marked.min.js) | Markdown 解析与渲染 |

## 样式说明

### Markdown 渲染样式

- 标题：带有底部边框分隔，层级分明
- 代码块：深色背景，圆角边框，支持横向滚动
- 行内代码：浅灰背景，圆角内边距
- 表格：全宽显示，表头浅灰背景，边框清晰
- 引用块：左侧蓝色边框，灰色文字
- 链接：蓝色文字，悬停下划线
- 列表：标准缩进，间距舒适

### 状态指示器

| 状态 | 颜色 | 说明 |
|------|------|------|
| 灰色 | `#ccc` | 初始状态 |
| 绿色 | `#4caf50` | 加载完成 |
| 橙色 | `#ff9800` | 加载中（呼吸动画） |
| 红色 | `#f44336` | 加载失败 |

## 文件结构

```
project/
├── index.html       # 您的主页面
├── README.html      # 使用说明预览页面
├── README.md        # 使用说明文档（Markdown 格式）
└── marked.min.js    # Markdown 解析（也可以使用CDN：https://cdn.jsdelivr.net/npm/marked/marked.min.js）
```

## 注意事项

- 请确保 `README.md` 与 `README.html` 位于**同一目录**下
- 若文件不存在或加载失败，页面会显示错误提示
- 支持标准 Markdown 语法（GitHub Flavored Markdown）
- 建议将 `README.md` 作为项目的使用说明文档维护，内容更新后页面会自动同步
